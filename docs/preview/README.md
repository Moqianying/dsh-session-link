# 界面截图

这里放 README 用的截图。文件名约定：

| 文件 | 内容 |
| --- | --- |
| `settings.png` | 设置 → 会话互联：左侧导航高亮、组标签、勾选状态、展开的预览 |
| `preview.png` | 同一会话的双视角对比（「它收到的记忆」与「它会提供的内容」） |
| `ui.png`（可选） | 独立选择页 `/api/session-link/ui` |

采集方法：`./scripts/capture.ps1`（会打印清单并打开需要的页面）。

## 采集清单

- 尺寸 1280×800 或 1600×1000，深色主题，浏览器缩放 100%，只截应用窗口。
- 至少 3 个会话、2 个勾选 1 个不勾——能同时展示"已链接/未链接"两种状态。
- 让预览面板展开着截，它是这个插件最有辨识度的部分。
- **隐私**：会话标题常带真实项目名/人名。截图前把标题改成本地示例，或截图后打码。

## 嵌入根 README 的片段

图片放好后，把下面这段贴到根 `README.md` 的「特性」之后：

```markdown
## 界面

| 设置面板 | 双视角预览 |
| --- | --- |
| ![设置面板](docs/preview/settings.png) | ![双视角预览](docs/preview/preview.png) |
```

> 顺序很重要：**先把图片文件提交进去，再加这段 markdown**，否则 GitHub 会显示碎图标。
