# 界面截图

这里放 README 用的截图。三张图（第三张可选），文件名固定：

| 文件 | 内容 | 必备要素 |
| --- | --- | --- |
| `settings.png` | 设置 → 会话互联 | 左侧导航高亮在「会话互联」、链环图标、组标签、勾选状态（有勾有不勾）、展开的预览面板 |
| `preview.png` | 双视角对比 | 同一会话的两个页签：「它收到的记忆」与「它会提供的内容」；可两张竖拼或并排 |
| `ui.png`（可选） | 独立选择页 `/api/session-link/ui` | 不依赖设置面板的入口，证明还有第二条通路 |

采集方法：`./scripts/capture.ps1`（打印清单并打开需要的页面）。

## 硬性要求

| 项 | 要求 | 原因 |
| --- | --- | --- |
| 尺寸 | 1200–1600 px 宽，宽高比接近 16:10 | GitHub README 正文约 880 px 宽，太宽会被缩糊、太窄显得空 |
| 缩放 | Windows 显示缩放 **100%**，浏览器缩放 100% | 125%/150% 截出来字边缘发虚，缩放到 README 宽度后更糊 |
| 主题 | 深色（与 README 演示一致）；可另备一张浅色 | 两张混用会显得随便 |
| 格式 | PNG；单张 < 500 KB（超了用 `pngquant` 或截图工具存 JPEG 90%） | 仓库不是图床，别塞几 MB |
| 裁剪 | **只截应用窗口**：不含桌面壁纸、任务栏、其它标签页、地址栏里的个人信息 | 截图会永久留在仓库历史里 |

## 画面里必须有的东西

- 「会话互联」在设置导航中**被选中高亮**（这是最容易让人一眼看懂的信号）
- 三个以上会话，**至少一个已链接、一个未链接**（同时展示两种状态）
- **展开着的预览面板**——这是本插件最有辨识度的部分，别只截列表
- 组标签上的人数（例如 `研究线 3`）与「共 N 个会话 · M 个链接组」的副标题

## 截图前请清理（重要）

- **个人化皮肤 / 桌面挂件**：右下角的挂件、自定义 UI 皮肤会让人以为是插件自带的，先关掉或裁掉
- **真实会话标题**：常带项目名、人名、内网地址。改成本地示例（如「示例会话 A」）或截图后打码
- **账号信息**：用户名、邮箱、头像、token、内网 URL 都不要进画面
- 浏览器只开一个标签页，别露书签栏里的私人条目

## 采集步骤（Windows）

1. `Win + Shift + S` 框选窗口区域（或 `Alt + PrtScn` 截当前窗口），存到 `docs/preview/`
2. 按上表改名：`settings.png` / `preview.png` / `ui.png`
3. 复核：`Get-ChildItem docs/preview/*.png | Select Name,Length`
4. **先提交图片**，再加 README 里的 markdown（顺序反了 GitHub 会显示碎图标）
